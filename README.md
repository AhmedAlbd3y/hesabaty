# حساباتي — دفتر الحسابات المالي الشخصي

تطبيق ويب تقدمي (PWA) باللغة العربية لإدارة المصاريف، المتاح، الأقساط، والمبالغ المنتظرة مع دعم كامل للهجة المصرية وتصميم زجاجي ثلاثي الأبعاد عصري.

## طريقة الرفع والتحديث على GitHub Pages:
1. ارفع ملفات هذا المجلد مباشرة إلى مستودعك (Repository) على GitHub في الفرع الرئيسي `main`.
2. تأكد من تفعيل **GitHub Pages** من `Settings` -> `Pages` واختيار فرع `main`.
3. افتح الرابط على هاتفك، وسيتم تحديث التطبيق إلى الإصدار الجديد فوراً.
