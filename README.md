# حساباتي V3
تطبيق ويب (PWA) بيشتغل بدون نت، وبياناتك بتتحفظ على جهازك بس.

## التثبيت
1. ارفع محتويات المجلد على استضافة HTTPS مجانية (Netlify Drop / GitHub Pages / Cloudflare Pages) بحيث index.html في الجذر.
2. افتح الرابط في Chrome على الموبايل ← القائمة ⋮ ← "تثبيت التطبيق" (Install app).
3. هيظهر على الشاشة الرئيسية ويفتح بدون شريط المتصفح.

## النسخ الاحتياطي
من تاب "كل الدفاتر" ← تصدير نسخة. احتفظ بالملف في Drive أو على الكمبيوتر.
